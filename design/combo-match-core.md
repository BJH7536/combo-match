## 0. 확정된 구조적 결정

이 6개가 게임의 형태를 정의한다. 하위 모든 수치는 여기서 의미를 파생받는다.

| # | 결정 | 선택 | 근거 |
|---|---|---|---|
| **D-1** | 매칭 모델 | **느슨한 Dobble** — 카드당 심볼 k(1~6), 요구 공통 심볼 r(1~4)을 자유 튜닝 | 정통 사영평면(모든 두 카드가 정확히 1개 공유)은 난이도 축이 없음. k·r을 노브로 풀면 지각 난이도가 연속 조절됨 |
| **D-2** | 매칭 표시 | **매칭 가능 카드를 표시하지 않는다** | "직접 찾기"가 코어 재미. 표시 제거의 공백은 유료 🔍힌트 아이템이 대체 (아이템 존재 이유가 설계에서 나옴) |
| **D-3** | 해결 가능성 | **생성 시 보장(by construction)** — 해답 체인을 먼저 깔고 장치를 덧입힘 | 검증-후-재생성 루프보다 빠르고 실패 없음. 모든 규칙 장치는 해답 순서 기반으로 배치되어 데드락이 구조적으로 불가능 |
| **D-4** | 난이도 실측 | **만 번 봇 시뮬레이션이 난이도의 진실** — 정적 점수는 보조 | 가중합 추정보다 클리어율·분기계수 실측이 체감 난이도를 잘 예측. 봇이 준수할 수 없는 장치(실시간 타이머 등)는 도입 안 함 |
| **D-5** | 실패 모델 | 소프트 — 패배해도 25% 위로 골드. 하드 실패는 💣폭탄(예고된 수 카운터)뿐 | 캐주얼 이탈 방지. 폭탄은 카운터가 항상 노출되어 공정 |
| **D-6** | 수익 모델 경계 | 골드는 인게임 획득 전용, 현금 결제 설계 없음 (프로토타입 범위) | 경제는 진행감 장치로만 사용 |

## 1. Overview

플레이어 앞에 카드들이 겹쳐 깔려 있다(피라미드/스택/격자). 하단에 **액티브 카드** 1장이 있고, 보드의 free(덮이지 않은) 카드 중 액티브와 **심볼을 r개 이상 공유하는 카드를 찾아 탭**하면 그 카드가 제거되며 **새 액티브가 된다**(체이닝). 연속 성공은 **콤보**를 쌓아 점수를 배가시키고, 막히면 **덱**을 뽑아 새 액티브를 받는다(콤보 리셋). 보드를 모두 비우거나(전체 제거) 목표 심볼을 다 모으면(수집) 승리. 판이 끝나면 점수가 **골드**로 환전되고, 골드로 🔍힌트·🧲집게·🌟와일드를 사서 다음 판을 유리하게 만든다.

**차별점**: ① 솔리테어(랭크 ±1)가 아니라 **시각 탐색(같은 그림 찾기)** 이 코어 — Dobble의 재미를 트라이픽스 구조에 이식 ② 레벨마다 다른 **규칙 장치**(열쇠·폭탄·수집·구역·종이)가 퍼즐의 성격을 바꿈 ③ 모든 레벨은 **만 번 시뮬레이션 성적표**(클리어율·시행횟수·아이템 소모·골드 기대치)를 갖고 출고됨.

## 2. Player Fantasy

**"눈썰미로 연쇄를 이어가는 카드 명탐정."** 잘 찾으면 콤보 불꽃이 커지고, 못 찾으면 덱이 마른다.

| 판타지 요소 | 이를 참으로 만드는 메카닉 |
|---|---|
| "내 눈이 좋아서 이긴다" | 매칭 후보 무표시(D-2) — 탐색 속도가 곧 실력. 심볼 풀·유사도·시각 변형이 탐색 난이도를 조절 |
| "연쇄가 끊기면 아깝다" | 콤보 = 점수 배수 + 장애물(lockReq) 해제 조건 + ×cgoal 보상 게이지 |
| "막판 한 수의 짜릿함" | 덱·와일드가 유한 → 마지막 자원으로 뚫는 순간이 릴리프 |
| "퍼즐을 여는 손맛" | 열쇠→자물쇠, 조각→종이 찢기, 구역 개방 — 명시적 "해금" 연출 |

## 3. Design Pillars

1. **찾는 재미가 우선** — 시스템은 탐색을 방해(어렵게)할 수는 있어도 대신 찾아주지 않는다. 힌트는 유료다.
2. **모든 레벨은 증명된다** — 생성 시 해답 보장(D-3) + 출고 전 만 번 실측(D-4). "우연히 못 깨는 레벨"은 존재하지 않는다.
3. **난이도는 계층으로 쌓는다** — 한 레벨에서 새로 조이는 축은 1개(§5 곡선 황금률). 여러 축 동시 강화 금지.
4. **경제는 진행감이다** — 수입은 레벨·난이도에 따라 자라고 가격은 고정 → 성장 체감 (§7).

## 4. 코어 규칙 명세

### 4.1 매칭·체이닝
- 보드 카드 C가 **선택 가능**하려면: free(덮은 카드 전부 제거) ∧ 열쇠 충족 ∧ 활성 구역 ∧ 종이 아님 ∧ 콤보 ≥ lockReq
- **매칭 성공**: `|C.symbols ∩ active.symbols| ≥ r` → C 제거, C가 새 액티브, 콤보 +1
- **점수**: 매칭당 `10 × 콤보`. 콤보가 `cgoal`의 배수마다 보너스 `+100 × 콤보`
- **덱 드로우**: 액티브 교체(스톡 우선, 소진 시 풀에서 랜덤 k개), **콤보 0으로 리셋**, 폭탄 카운터 감소
- **승리**: 전체 제거 또는 수집 목표 달성(조기 승리). **패배**: 유효 매칭·덱·와일드 모두 소진 / 이동 제한 / 💣 폭발 / 보드 소진에도 수집 미달

### 4.2 규칙 장치 (F계층) — 전부 시뮬 봇이 준수
| 장치 | 필드 | 규칙 | 생성 불변식 (데드락 방지) | 우회 |
|---|---|---|---|---|
| 🔑 열쇠-자물쇠 | `unlockedBy:[ids]` | 지정 열쇠 카드 제거 후에만 선택 가능 | 해답 순서상 **앞선 카드만 열쇠** → 항상 DAG | 집게만 가능, 와일드 불가 |
| 💣 폭탄 | `bombCounter:n` | 모든 행동(매칭·드로우·집게)마다 −1, 0이면 즉시 실패 | 카운터 = 해답 순서 위치+7 (최단 제거거리+6 여유). 뒤집힌 카드·종이 카드 금지 | 제거 = 해체 |
| 🎯 수집 목표 | `rules.collectGoal` | 지정 심볼 N개 수집 시 **조기 승리**. 보드 소진에도 미달이면 실패 | 목표 = 최다 심볼 빈도의 75% (최소 3) | — |
| 🗺️ 구역 | `zone:0..2` | 낮은 구역을 전부 비워야 다음 구역 선택 가능 | x분할 후 "덮는 카드를 덮인 구역으로 강등" 고정점 + 구역 순서 해답 체인(경계 심볼 연결 자동 보장) | 집게만 가능 |
| 🧻 종이+🧩 조각 | `paper` / `piece` + `rules.paper` | 종이 카드는 심볼 은닉+선택 불가. 조각 piecesNeeded개 수집 시 전체 해방 | 종이 = 해답 순서 **꼬리** 구간, 조각 = 그 앞 구간 → 순서대로 풀면 반드시 열림 | 집게만 가능 |
| 🔒 콤보 잠금 | `lockReq:n` | 현재 콤보 ≥ n일 때만 제거 가능 | 해답 앞 3장에는 배치 안 함 | 집게 |
| ❔ 뒤집힘 | `faceDown` | free가 되기 전까지 심볼 미공개 (인간 전용 난이도 — 봇 영향 없음) | — | — |

### 4.3 아이템 (판 안에서 골드로 구매, 가격 고정)
| 아이템 | 가격 | 효과 | 설계 의도 |
|---|---|---|---|
| 🔍 힌트 | 120 | 매칭 가능 카드 1장을 2.5초 표시 | D-2(무표시)의 유료 대체재 |
| 🧲 집게 | 350 | **모든 게이트 무시**하고 아무 카드 1장 제거(콤보·액티브 유지). 재클릭 취소·환불 | 구조 자체를 푸는 프리미엄. 유일한 게이트 우회 수단 |
| 🌟 와일드 | 500 | 아무 free 카드나 매칭 처리(구조 게이트는 못 뚫음) | 심볼 운 보정. 시작 보유분(config.wild) 소진 후 구매 |

## 5. 난이도 시스템

### 5.1 노브 계층 (A~F)
| 계층 | 노브 | 범위 |
|---|---|---|
| **A 지각** | 심볼 풀 N(4~40) · 카드당 k(1~6) · 요구 r(1~4) · 유사도(0~2) · 시각변형(0~60%) | 탐색을 어렵게 |
| **B 구조** | 카드 수(4~40) · 레이어(1~5) · 레이아웃(피라미드/스택/격자) · 🔑열쇠(0~8) · 🗺️구역(1~3) · 🧻종이(0~40%) | 선택지·접근성 축소 |
| **C 자원** | 덱(0~30) · 와일드(0~3) · 이동제한 · 콤보목표(3~15) · 목표유형 | 여유 축소 |
| **D 압박** | 💣폭탄(0~4) · 장애물%(lockReq) · 뒤집힘% · (셔플·시간 — 도입 보류) | 실패 조건 추가 |
| **E 경제** | 레벨 번호(1~200) | 보상 곡선 (§7) |

### 5.2 난이도 점수
- **정적 점수** (0~100): 노브 가중합. A(.15/.20/.20/.15/.10) B(.10/.15/.20/.10/.08/.08) C(.15/.10/.10/.10) D(.15/.15/.10/.10/.12)
- **실측 점수**: `100×(0.65×P(stuck) + 0.35×(1−(B−1)/3))` — P=봇 실패율, B=평균 분기계수
- **종합** = 0.5×정적 + 0.5×실측. 등급: <25 튜토리얼 / <45 쉬움 / <62 표준 / <80 어려움 / ≥80 하드코어
- 권장 밴드: 튜토리얼 P<2%·B≈3~4 / 표준 P 5~15%·B 2~3 / 하드 P 20~35%·B 1.3~2

### 5.3 진행 곡선 (황금률: 한 레벨에 새 축 1개)
| 구간 | 도입 |
|---|---|
| 1–10 | A 최소 (k2 r1 N6~8, 격자·레이어1) |
| 11–40 | +B (레이어·카드 수, 피라미드) |
| 41–100 | +C (덱 압박, r=2, 유사 심볼군) + 🎯 수집 |
| 100+ | +D/F (폭탄·열쇠·구역·종이, r=3 스파이크) |

## 6. 자동 설계 & 평가 프레임워크 (툴 명세)

**파이프라인**: `목표 난이도(5~95) → 아키타입 4종(피라미드 표준/스택 겹침/격자 지각집중/장애물 압박) × 지터 → 후보 8개 생성 → 각 300회 검증 → 종합점수 최근접 선택` (후보 클릭으로 동일 난이도 다른 패턴 교체)

**대량 평가**: Web Worker에서 N회(기본 10,000, ~0.4초) 봇 플레이(랜덤=초보 / 그리디=합리적: 폭탄 해체>언커버 우선 / 혼합). 산출: 클리어율 → **예상 시행횟수**(=1/클리어율), 판당 **아이템 소모**(덱+와일드), 평균 점수(승/패 분리) → **골드/판 기대치·클리어까지 기대 골드**, 실측 분기 B, 실측 종합 난이도. 결과는 export JSON의 `evaluation` 블록에 영구 기록.

**직접 조정**: 자동 결과가 수동 노브에 반영(이어서 조정 = 수동 모드), 보드 카드 클릭 → 심볼/잠금/뒤집힘 편집(재검증 자동, 평가 무효화). 모드 배지 ⚡자동/🎛수동/✏️편집됨.

## 7. 경제 명세

```
기본골드  = 15 + 3×레벨번호               # 진행 보상 (선형)
점수환율  = 0.01 × (1 + 난이도/40)         # 어려울수록 점수당 골드↑
승리 골드 = 기본골드 + 점수×환율 · 패배 = ×0.25 위로보상
지갑: localStorage 영속, 신규 200골드 · 아이템 가격 고정(120/350/500) → 수입 성장 = 파워 진행
```
검증 예: 난이도 40 기준 — 레벨 5 승리 ≈ 🪙82, 레벨 40 ≈ 🪙187. 평가표가 레벨별 "클리어까지 기대 골드"를 산출하므로 **아이템 가격 대비 수급 밸런스를 수치로 검증**할 수 있다 (권장: 클리어까지 기대 골드 ≈ 힌트 1~3개 가격).
