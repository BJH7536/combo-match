# 레벨 메카닉 브레인스토밍 2차 — 제약 · 재미 · 난이도

> 1차(`level-mechanics-brainstorm.md`, 장치 7종 도입 완료) 이후의 확장 라운드.
> 전제: 장치 7종 + 콤보 보상 트랙 + 드로우 제한 레벨 + 만 번 시뮬 검증 체계가 이미 가동 중.
> Game Feel 플레이테스트(2026-07-30)의 통찰 반영: **제약은 손실 피드백과, 보상은 정점 연출과 함께 가야 감각이 된다.**
>
> 평가 기준(1차와 동일 + 1개 추가):
> ① 봇 측정 가능성(시뮬 검증 체계 활용) ② 데드락 안전 생성 가능 ③ 엔진 이식 난도 ④ **"특정 전략으로 풀리는 제약인가"** — Balatro 챌린지 철학: 좋은 제약은 난이도가 아니라 *새 퍼즐*이다 (무차별 반복이 아니라 전략 전환을 요구).

## 우선 도입 추천 (S등급 5건의 시너지)

**"챌린지 팩" 한 묶음으로 도입하면 서로를 강화한다:**

1. **A1 이동 예산**은 구현이 0에 가깝고(이미 있는 knob), 즉시 새 레벨 유형("정확도 레벨")을 만든다 — 드로우 제한(↺)과 함께 매 스테이지 7번째 배치 권장
2. **B2 별점**이 A1과 결합하면 "클리어는 쉽게, 3성은 어렵게" — 난이도 곡선을 건드리지 않고 심화 도전 제공. **별 컷은 만 번 시뮬의 p50/p90로 자동 산정** (수동 밸런싱 불요 — 우리 검증 체계의 고유 강점)
3. **B1 피버**는 플레이테스트의 핵심 비판("정점이 평평하다")을 규칙 차원에서 해소 — 카니발 연출(P1)과 같은 순간에 발동
4. **B3 데일리 시드**는 자동 설계 파이프라인을 그대로 재사용하는 최저비용 리텐션 장치
5. **C1 DDA**는 레벨 데이터를 건드리지 않아 검증 체계와 충돌하지 않는 유일한 난이도 완화 방식

도입 순서 제안: A1(생성기 knob) → B2(별점+시뮬 컷) → B1(피버) → B3(데일리) → C1(DDA).
각 단계는 독립 배포 가능하며, 전부 기존 3중 검증 게이트(해답 보장·밴드·그리디 40시드)를 통과해야 한다.
