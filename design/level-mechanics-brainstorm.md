# 레벨 조절 요소 — 서칭 & 브레인스토밍

> 목적: 기존 4계층 난이도 노브(지각/구조/자원/압박) **위에 얹을 수 있는 "레벨 규칙 장치"**를 조사하고,
> 사용자 제안 4종 + 확장 후보들의 적합성을 평가한다.
> 전제: 우리 게임은 Dobble형 심볼 매칭 콤보 게임 (액티브 카드와 r개 심볼 공유 → 체이닝, 만 번 시뮬레이션 평가 프레임워크 보유).

---

## 1. 장르 조사 요약

### Candy Crush 블로커 분류학 (가장 체계적인 선행 사례)
매치3의 블로커는 **기능**으로 분류된다:
- **접근 차단**: 자물쇠(liquorice lock)·마멀레이드·설탕상자 — 매치 전까지 조각 사용 불가
- **공간 점유**: 프로스팅(최대 5겹)·케이크밤 — 제거 전까지 자리 차지
- **기능 무력화**: liquorice shell/swirl — 특수 캔디 효과 차단
- **증식/전파**: 초콜릿·초콜릿 분수 — 매 턴 번식하는 "능동적 적"
- **시한 실패**: 캔디밤 — **n수 안에 제거 못하면 즉시 실패**
- **매칭 방해**: 캔디케인 펜스 — 인접 매칭 차단

### 타일 매칭 (Zen Match / Tile Busters / Triple Match 3D)
- **얼음·사슬·접착제·상자**: 여러 번 매치하거나 특정 조건으로만 해제
- **타일 생성기**: 제거해도 계속 새 타일 공급
- **랙 제한**(7칸): 보관함이 차면 실패 — 자원 압박의 공간 버전
- 시간 마일스톤 별점 — 속도 보상

### 모던 솔리테어 (Disney Solitaire / TriPeaks 계열)
- **그림 액자(picture frame)**: 더미 일부를 그림이 덮음 — 특정 카드 아래 묻힌 **그림 조각을 모으면** 액자가 풀리며 더미 해방 ← 사용자 제안 ②와 정확히 동일 계열
- **스트릭/콤보 미터** 및 콤보 보상 (이미 우리 게임에 있음)
- 보조 수집물(모래 속 보물 등): 특정 카드를 지나가야 얻는 서브 목표

### 기능 6축 프레임 (조사 종합)
모든 장치는 아래 6축 중 1개 이상을 조작한다. **우리 4계층과의 매핑**:

| 기능 축 | 설명 | 우리 계층 |
|---|---|---|
| ① 순서 강제 | 특정 순서/구역부터 제거하도록 강제 | B 구조 (분기 축소) |
| ② 정보 은닉 | 심볼을 가려 계획을 방해 | A 지각 |
| ③ 목표 재정의 | 전체 제거 외의 서브/우선 목표 부여 | C 자원 (행동 배분) |
| ④ 시한 압박 | n수/n초 안에 특정 행동 강제 | D 압박 |
| ⑤ 능동 방해 | 시간이 지나면 스스로 악화 | D 압박 |
| ⑥ 자원 소모 강제 | 특정 자원을 반드시 쓰게 만듦 | C 자원 |

## 2. 사용자 제안 4종 심층 분석

### ② -1. 순서 강제 — "무조건 어느 부분부터 먼저"
**구체화**: 번호 게이트 카드(①→②→③ 순서로만 제거 가능) 또는 열쇠🔑→자물쇠 체인(열쇠 카드를 제거해야 자물쇠 카드가 열림).
- 기존 `lockReq`(콤보 조건)와 다름 — 이건 **위상(topology) 조건**.
- **적합성: ★★★★★ (S)** — 분기계수를 국소적으로 1로 만들어 "경로 퍼즐"을 창출. 우리 커버리지 그래프(coveredBy)에 `unlockedBy: [cardId]` 필드 하나로 자연 확장.
- **시뮬 측정**: 완벽 (봇이 그대로 준수 → P/B 실측에 반영).
- 리스크: 남용 시 외길이 되어 Dobble의 "찾는 재미"가 죽음 → 게이트는 보드의 20% 이하 권장.

### ② -2. 종이 가림 + 조각 수집 — "가려진 부분 때문에 다른 조각을 모아서"
**구체화**: 보드 일부 영역이 종이🧻로 덮여 **심볼이 안 보이고 선택 불가**. 흩어진 조각 카드 🧩 n개를 제거(수집)하면 종이가 찢어지며 영역 해방.
- Disney Solitaire의 그림 액자+조각과 동일 계열 — 장르 검증 완료된 장치.
- **적합성: ★★★★☆ (A)** — ①순서강제+②정보은닉+③목표재정의 3축 복합. 서사적 연출("종이를 찢는" 쾌감)도 좋음.
- **시뮬 측정**: 부분적 — 조각 수집 순서 강제는 측정 가능. 정보 은닉 효과는 봇에게 없음(인간 전용 난이도) → 평가표에 "지각 보정 +α"로 표기 필요.
- 리스크: 조각이 종이 뒤에 갇히는 데드락 → 생성기가 "조각은 반드시 종이 밖" 불변식을 보장해야 함.

### ② -3. 시간 내 우선 제거 — "시간 내에 해당 그림을 먼저 빼야"
**구체화 A (수 기반, 권장)**: 폭탄 카드💣 — 카운터 n이 붙고 **n수 안에 제거 못하면 실패**(캔디밤 직계).
**구체화 B (초 기반)**: n초 타이머 — 실시간 압박.
- **적합성: A안 ★★★★★ (S) / B안 ★★★☆☆ (B)** — 수 기반은 턴 구조와 정합하고 시뮬로 완벽 측정 가능. 초 기반은 봇이 측정 불가(인간 전용)+모바일 캐주얼에서 스트레스 민원 다수.
- **시뮬 측정**: A안 완벽 / B안 불가.
- 리스크: 폭탄이 덮인 채로 스폰되면 불공정 → 폭탄은 free 상태로만 배치, 카운터는 여유롭게(카드까지의 최단 제거거리 + 3 이상).

### ② -4. 특정 부분 먼저 소진 — "특정 부분을 먼저 소진시켜야"
**구체화**: 구역 쿼터 — 보드를 구역(왼쪽 더미/오른쪽 더미)으로 나누고, **A구역을 모두 비워야 B구역이 잠금 해제**. 또는 소프트 버전: A구역을 비우면 보상(덱+2).
- 순서 강제의 공간 스케일업 버전. TriPeaks의 봉우리별 클리어 보너스와 유사.
- **적합성: ★★★★☆ (A)** — 레이아웃 디자인과 시너지(3봉우리 피라미드가 자연스러운 구역). 하드 잠금은 사실상 "레벨을 2막으로 분할"하는 효과.
- **시뮬 측정**: 완벽.
- 리스크: 하드 잠금 + 심볼 체인이 어긋나면 A구역 소진 시점에 액티브가 B구역과 연결 안 될 수 있음 → 생성기가 구역 경계에서 체인 연결 보장 필요.

## 3. 확장 브레인스토밍 (조사에서 도출한 추가 후보)

| 후보 | 설명 | 기능축 | 적합성 | 시뮬 | 비고 |
|---|---|---|---|---|---|
| 🔑 **열쇠-자물쇠** | 열쇠 카드 제거 → 지정 자물쇠 해제 | ① | **S** | ✅ | 순서 강제의 최소 구현. ②-1과 통합 가능 |
| 🎯 **심볼 수집 목표** | "🍓 12개 수집" — 목표 유형 collect의 구체화 | ③ | **S** | ✅ | 이미 objective 슬롯 존재, 구현만 남음 |
| 🦠 **오염 전파** | 매 n수마다 인접 카드 1장을 잠금으로 오염(초콜릿 계열) | ⑤ | A | ✅ | 유일한 "능동적 적" — 속도를 강제. 과하면 스트레스 |
| 🧊 **다중 커버(HP)** | 얼음 카드 — 같은 카드를 2번 매칭해야 제거(프로스팅 겹) | ⑥ | B+ | ✅ | 이동 수 소모 강제. 콤보 체인과 궁합 좋음(제거 없이 콤보 유지) |
| 💰 **골드 카드** | 제거 시 즉시 골드 — 경로 선택에 경제 유인 | ③ | A | ✅ | 기존 경제 시스템과 직결. "위험한 경로에 보상" 설계 가능 |
| 👯 **쌍둥이 카드** | 두 쌍둥이를 연속(콤보 안 끊고) 제거해야 함께 사라짐 | ①+④ | B | ✅ | 콤보 시스템과 고유 시너지 — 다른 게임에 없는 우리만의 변형 |
| 📥 **랙 제한** | 타일매칭식 보관함 | ⑥ | **부적합** | – | 우리 코어(체이닝)와 충돌 — 별도 게임이 됨 |
| 🔀 **주기 셔플** | n수마다 재배치 | ⑤ | 보류 | ⚠️ | 이미 D계층에 노브 존재(런타임 미구현). 작업기억 무효화는 불쾌 민원 다수 |
| ⏱️ **실시간 타이머** | 레벨 전체 제한시간 | ④ | 보류 | ❌ | 봇 측정 불가 + 캐주얼 이탈 요인. 별점(속도 보너스)으로만 활용 권장 |

## 4. 평가 매트릭스 (도입 우선순위)

평가 기준: 코어 시너지(콤보 체이닝과 상호작용) / 시뮬 측정 가능성(우리 프레임워크 강점 활용) / 구현 난도 / 인지 부하.

| 순위 | 장치 | 등급 | 코어 시너지 | 시뮬 | 구현 | 판정 |
|---|---|---|---|---|---|---|
| 1 | 🔑 열쇠-자물쇠 (순서 강제) | **S** | 높음 | ✅ | 낮음 | **1차 도입** — `unlockedBy` 필드 하나 |
| 2 | 💣 폭탄 카드 (수 기반 시한) | **S** | 높음 | ✅ | 낮음 | **1차 도입** — 실패 조건 다양화 |
| 3 | 🎯 심볼 수집 목표 | **S** | 중간 | ✅ | 낮음 | **1차 도입** — objective 슬롯 완성 |
| 4 | 🗺️ 구역 쿼터 (부분 소진) | **A** | 높음 | ✅ | 중간 | 2차 — 생성기 체인 연결 작업 필요 |
| 5 | 🧻 종이+조각 수집 | **A** | 중간 | ⚠️ 부분 | 중간 | 2차 — 연출 가치 높음, 지각 난이도는 봇 미측정 |
| 6 | 🧊 다중 커버(HP) | B+ | 중간 | ✅ | 낮음 | 2차 — 값싼 다양성 |
| 7 | 🦠 오염 전파 | A- | 중간 | ✅ | 중간 | 3차 — 밸런스 민감, 시뮬 필수 |
| 8 | 👯 쌍둥이 카드 | B | **독창** | ✅ | 중간 | 3차 — 우리만의 시그니처 후보 |
| – | 랙 제한 / 주기 셔플 / 실시간 타이머 | – | – | – | – | 도입 안 함 (충돌/민원/측정 불가) |

**핵심 판단 근거**: 우리 프레임워크의 경쟁력은 "만 번 시뮬로 난이도를 실측"하는 것 → **봇이 준수·측정할 수 있는 규칙 장치를 우선**한다. 시간·정보은닉형은 인간 전용 난이도라 정적 가중치로만 반영되고 실측이 안 되므로 후순위.

## 5. 스키마 확장 스케치 (`combo-match/level@2` 후보)

```jsonc
"cards": [{
  "id": 0, "symbols": ["🍓","🍇"], "lockReq": 0, "faceDown": false,
  "unlockedBy": [4, 7],       // 🔑 이 카드들이 제거되어야 선택 가능 (순서 강제)
  "bombCounter": 8,           // 💣 8수 안에 제거 못하면 실패 (0 = 없음)
  "hp": 2,                    // 🧊 2번 매칭해야 제거
  "zone": "left",             // 🗺️ 구역 태그
  "piece": true,              // 🧩 조각 카드 (수집 대상)
  "goldBonus": 30             // 💰 제거 시 즉시 골드
}],
"rules": {
  "zoneOrder": ["left","right"],          // 🗺️ left 소진 → right 해제
  "paperZones": [{"zone":"right","piecesNeeded":3}],  // 🧻 조각 3개 → 종이 제거
  "collectGoal": {"symbol":"🍓","count":12}           // 🎯 수집 목표
}
```

생성기 불변식 (데드락 방지):
1. `unlockedBy` 그래프는 커버리지 그래프와 합쳐도 DAG여야 함 (순환 금지)
2. 폭탄 카운터 ≥ (해당 카드까지 최단 제거 거리 + 3)
3. 조각 카드는 종이 구역 밖에만 배치
4. 구역 경계에서 해답 체인의 심볼 연결 보장 (A구역 마지막 카드 ↔ B구역 첫 카드가 r개 공유)

## 6. 다음 단계 제안

1. **1차 도입 3종**(열쇠-자물쇠 · 폭탄 · 심볼 수집)을 디자이너 노브 + 게임 런타임 + 시뮬 봇에 동시 구현 → 만 번 평가로 난이도 기여 실측
2. 실측 후 `difficulty()` 가중치에 신규 장치 항목 추가 (예: 폭탄 1개당 압박 +x)
3. 2차(구역/종이)는 생성기 불변식 구현과 함께
