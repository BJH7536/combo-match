🎆 콤보 연출 시안 3종

각 시안은 콤보 ×1→×10 상승을 자동 반복 재생합니다. 콤보가 높을수록 연출 강도가 단계적으로 상승하며, ×5·×10에서 마일스톤 연출이 터집니다. 마음에 드는 시안을 선택하시면 게임(play.html)에 이식합니다.

시안 A · 🔥 화염 스택 (Fire Escalation)

콤보마다 불꽃 파티클이 카드에서 솟아오르고 배지가 커지며 흔들린다. 단계별 티어 텍스트(GOOD→GREAT→HOT→BLAZING→LEGENDARY)가 팝업. 고콤보에선 화면 가장자리가 달아오르는 비네트 글로우. — 직관적·중독적, 시각 부하 중간

COMBO×1
추천 상황: 캐주얼 메인 타깃 · 기존 목업(🔥 COMBO)과 연속성 최고

시안 B · ⚡ 전기 체인 (Electric Chain)

매칭 순간 카드→배지로 번개 아크가 튀고 배지가 전기 펄스로 진동. 콤보가 높을수록 번개 갈래가 늘고, ×5·×10에서 화면 백색 플래시 + 다중 낙뢰. — 스피디·타격감 강조, 연쇄(체인) 테마와 의미적 일치
🥝🍒
CHAIN×1
추천 상황: 콤보 속도전 강조 빌드 · 타이머/폭탄 레벨과 톤 일치

시안 C · 🌟 스타 카니발 (Star Carnival)

매칭마다 별 버스트가 사방으로 터지고 배지는 무지개 그라데이션 회전. ×5·×10 마일스톤에서 대형 배너 줌("×10 SPECTACULAR!") + 콘페티 샤워. — 축제감 최대·보상 체감 최고, 시각 부하 높음
