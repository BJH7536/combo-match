## 3. 지금까지 구현된 것 (수정 이력 순)

### 3.1 기반 (툴 v1)
- 난이도 리서치 → **4계층 노브**(A지각·B구조·C자원·D압박) 정의, 정적 난이도 점수(가중합)
- 레벨 디자이너: 노브 조절 → **해답 체인 선배치(solvable-by-construction)** 생성 → 몬테카를로 검증(막힘확률 P·분기계수 B) → JSON export
- 게임(play.html) 제작 + **핸드오프 3채널**: localStorage(`combo-match:playtest`) / URL 해시(`#level=<base64>`) / 파일

### 3.2 자동 설계 + 평가 프레임워크 (툴 v2)
- **자동 설계**: 목표 난이도(5~95) → 아키타입 후보 8개 생성·300회 검증 → 최근접 자동 선택 (후보 클릭으로 패턴 교체, 🔀 재추첨)
- **대량 평가**: Web Worker에서 10,000회 봇 플레이(랜덤/그리디/혼합) → 클리어율·**예상 시행횟수**·**아이템 소모**·평균 점수(승/패)·실측 난이도. ~0.4초
- **직접 조정**: 자동→수동 연속 워크플로우, 보드 카드 클릭 편집(심볼·잠금·뒤집힘), 모드 배지(⚡/🎛/✏️)

### 3.3 경제 시스템
- 게임에서 **매칭 가능 카드 초록 표시 제거** (직접 찾기가 코어 재미 — GDD D-2)
- 아이템 3종: 🔍힌트 120 / 🧲집게 350 / 🌟와일드 500 (골드 구매, 집게만 모든 게이트 우회)
- 골드 공식: `기본골드=15+3×레벨번호`, `점수환율=0.01×(1+난이도/40)`, 패배 시 25% 위로보상. 지갑 localStorage 영속
- 디자이너 E그룹(레벨 번호 1~200) + 평가와 결합해 **골드/판·클리어까지 기대 골드** 산출

### 3.4 규칙 장치 5종 (F계층, 스키마 v2)
전부 "해답 순서 기반 배치 = 데드락 구조적 불가능" + **시뮬 봇이 준수**:
- 🔑 열쇠-자물쇠(`unlockedBy`) — DAG 보장. 와일드 우회 불가, 집게만 가능
- 💣 폭탄(`bombCounter`) — 모든 행동마다 −1, 0이면 실패. 카운터=최단거리+6
- 🎯 수집 목표(`rules.collectGoal`) — 최다 심볼 75%, **조기 승리**
- 🗺️ 구역(`zone`) — x분할+강등 고정점, 구역 순서 해답 체인(경계 심볼 연결 보장)
- 🧻 종이+🧩 조각(`paper`/`piece`) — 종이=해답 꼬리, 조각=머리 → 순서대로 풀면 반드시 열림

### 3.5 패턴 시스템
- 레이아웃 8종: 피라미드·스택·격자·**트라이픽스(봉우리 2~4)**·**다이아몬드**·**타워**·**웨이브**·**🧬복합(2~3패턴 혼합)**
- 전 패턴 **시드 파라미터 변형** — 검증: 패턴당 시드 120개 → **120/120 고유 레이아웃**, 960개 전부 해결 가능
- 자동 설계 아키타입 7종

### 3.6 콤보 보상 트랙 + 스타 카니발 연출 (G계층)
- 연출: 시안 3종 중 **스타 카니발 확정** — 별 버스트(콤보 비례)·무지개 배지·SPECTACULAR 배너·콘페티
- **보상 트랙**: 디자이너가 3슬롯 {콤보값×아이템} 정의 → 게임에서 도달 시 지급(레벨당 1회), 힌트·집게는 무료 충전(`🎁 무료 ×n` 칩)
- **난이도 연동**: `완화도=Σ가치×(10/콤보값)/3` → C자원 반영. 와일드·덱·집게는 봇이 실제 사용 → 실증: 후한 트랙 시 클리어율 8.6%→64.6%
- 자동 설계가 목표 난이도에 맞춰 트랙 스케일(쉬움=후함)

### 3.7 카드 치수 동적화 (최신)
- 심볼 수(k)에 따라 카드 크기 조정: k≤2 64×80 / k3~4 **108×96**(2열) / k5~6 **108×126**(2열×3행)
- 심볼 크기 고정(30px, 이모지 실측 41px 폭 기준 산정) → k=2와 동일한 여백. 레벨 JSON에 `cardW/cardH` 기록, 게임 동일 렌더
