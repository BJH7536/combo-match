## Note

Phaser 3.90.0은 v3 트리의 최종 릴리스이며 3.88의 드롭인 교체판이다.
LLM 학습 데이터가 3.x API를 충분히 커버하므로 엔진 레퍼런스 문서는 선택 사항.
에이전트가 잘못된 API를 제안하면 그때 문서를 보강할 것.

- 이후 개발은 전부 Phaser 4.x로 이동했다 (2026-07 현재 v4.2.1). **v4 API/예제를 혼용하지 말 것** —
  v4는 렌더러 재작성 등 구조가 다르다. 검색 결과가 v4 문서일 수 있으니 버전 표기를 확인할 것.
- `/setup-engine refresh`로 언제든 전체 레퍼런스 문서를 생성 가능.
