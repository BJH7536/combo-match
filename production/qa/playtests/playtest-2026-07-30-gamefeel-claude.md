## Test Focus

Steve Swink, *Game Feel: A Game Designer's Guide to Virtual Sensation* (2008)의 프레임으로 게임의 "감각 품질"을 평가한다.

**책의 핵심 주장 요약**
1. 게임 필 = **실시간 제어**(real-time control) × **시뮬레이션 공간**(simulated space) × **폴리시**(polish)
2. **보정 주기 100ms**: 지각→판단→행동→피드백 루프가 100ms 안에 돌아야 "내가 조작한다"는 감각이 성립
3. **6개 측정축**: Input(입력 기기·매핑) / Response(반응 곡선·타이밍) / Context(공간·카메라 맥락) / Polish(효과의 스펙트럼) / Metaphor(대상의 물리적 은유) / Rules(규칙이 감각에 부여하는 의미)
4. **ADSR 엔벨로프**: 반응의 어택-감쇠-서스테인-릴리즈가 타격감을 결정
5. **폴리시 스펙트럼**: 같은 상호작용도 효과의 밀도에 따라 전혀 다른 감각이 된다

**적용 주의**: 본 게임은 이산 입력(탭) 퍼즐로, Swink가 말하는 연속 실시간 제어는 없다. 따라서 평가는 ①탭→피드백 보정 주기 ②폴리시 스펙트럼 ③맥락 가독성 ④우드 콘솔 은유 ⑤규칙(콤보·보상)의 감각 증폭에 집중한다.

## First Impressions (First 5 minutes)
- **Understood the goal?** Yes — 첫 실행 온보딩 오버레이(①~⑤ + 장치 범례 + 아이템 가격)가 규칙을 한 화면에 전달. 레벨 1~3 튜토리얼 초록 하이라이트가 "무엇을 누를 수 있나"를 직접 보여줌
- **Understood the controls?** Yes — 탭 단일 입력. 와일드/집게 무장 상태는 슬롯 텍스처 전환 + "카드를 고르세요" 힌트로 전달
- **Emotional response**: Engaged — 매치 연쇄의 피치 상승이 즉각 "한 번 더"를 유발
- **Notes**: 스테이지 선택 → 레벨 → 플레이 왕복이 자연스럽고, 복귀 시 보던 스테이지가 유지됨

## Gameplay Flow

### What worked well (Swink 축별)
- **[Response] 보정 주기 통과**: 입력이 `pointerdown`에서 처리(NOT pointerup — 클릭 해제 대기 없음)되어 상태 변화는 1프레임 내, 시각 반응(석션)은 트레일링. **Swink의 100ms 기준을 여유 있게 통과**
- **[Response/ADSR] 오디오가 교과서적**: WebAudio 합성에 어택 6ms + 지수 감쇠 — 코드 주석("어택을 아주 짧게 잡아야 타격감이 산다")이 Swink의 ADSR 장을 그대로 실천. 장5음 펜타토닉 계단으로 **콤보가 오를수록 음이 상승**(11계단 상한 — "끝없이 높아지면 귀가 아프다"), 5도 중첩으로 두께. 리젝트는 하강 sawtooth — 성공/실패의 음색 대비 명확
- **[Polish] 인과를 보여주는 제거 연출**: 매치된 카드가 **스포트라이트로 빨려 들어가는 300ms 석션**(Cubic.easeIn) — "무엇과 맞았는지"를 애니메이션 궤적이 설명. 액티브 카드는 220ms Back.easeOut 스쿼시로 교체를 강조. 집게는 아래로 떨어뜨려 "치운다"를 구분
- **[Polish] 절제된 상승 연출**: 헤일로 펄스가 콤보에 비례, **카메라 셰이크는 콤보 3부터**(70~140ms, 강도 스케일) — "매 매칭마다 흔들면 눈이 피로하다"는 주석대로 과잉을 피함
- **[Response] 실패 피드백 3중**: 거부 시 카드 셰이크 + 하강음 + **원인별 토스트**("위에 카드가 덮여 있어요"/"콤보가 더 필요해요"...) — Swink: 실패도 반응이다
- **[Context] 기믹 가독성**: 종이(크라프트 줄무늬·심볼 은닉), 게이트(회청색), 하단 해제 조건 플레이트, 구역 색띠 — 직전 개편으로 "지금 못 집는 카드"가 텍스처 차원에서 구분됨 (레벨 26·28 실플레이 확인)
- **[Metaphor] 우드 콘솔 일관성**: 캔버스 합성 나무결·펠트·금장 칩 + 드로우의 **대역필터 노이즈(카드 마찰음)** — 그래픽·사운드 모두 외부 에셋 0으로 은유 유지
- **[Rules] 보상의 즉시성**: 콤보 ×3 골드 +50이 칩에 즉시 반영(200→250 실측), ×5 와일드 슬롯 ×1→×2 + 튕김 + 플로팅 — 규칙 보상이 화면 상태값으로 직결 (레벨 3 실측)
- **막힘 안내**: isStuck 감지 시 "🧲 집게로 카드를 치울 수 있어요" — 소프트 실패(D-5)를 감각으로 뒷받침

### Pain points (비판 — Swink 렌즈)
- **[Polish/Rules] 확정 연출 '스타 카니발'(마스터 §4.4)이 Phaser판에 미이식** — Severity: **High**
  cgoal 달성(+100×콤보, 게임 최대 보상 순간)이 **토스트 한 줄**("콤보 보너스 +550!")이다. 별 버스트·배너 줌·콘페티가 기획 확정본(play-reference)에는 있으나 본편에 없다. 폴리시 스펙트럼에서 **가장 큰 순간의 어택이 가장 약한 역전** 상태.
- **[Response] 드로우 = 손실인데 반응이 이득과 비슷** — Severity: **High**
  드로우는 콤보 리셋(손실 사건)이지만 마찰음 + 스포트라이트 팝뿐. 콤보 배지가 **소리 없이 0으로 변함** — 손실의 시각적 애도(배지 흔들림·회색 전환·게이지 드레인)가 없다. 또 덱→스포트라이트로 카드가 "날아오는" 궤적이 없어 새 액티브의 출처 인과가 약하다.
- **[Input] 눌림(press) 반응 부재** — Severity: Medium
  카드에 hover 리프트(-4px)는 있으나 **pointerdown 순간의 눌림**(스케일 다운/그림자 축소)이 없다. Swink: 물리적 존재감은 접촉 순간의 반응에서 나온다. 특히 터치(모바일)에는 hover가 없어 접촉 피드백이 소리뿐.
- **[Input] 모바일 최소 히트박스 42px** — Severity: Medium (기존 관찰 재확인)
  최밀 레벨(9열)에서 카드 42px < 애플 권장 44px. 오탭 → 리젝트 피드백 루프가 감각 품질을 갉아먹는 조합.
- **[Context] 단일 토스트 채널 경합** — Severity: Medium
  수집 진행·조각 진행·콤보 보너스·보상 획득·막힘 안내가 **같은 toastText 한 개**를 공유 — 연쇄 중 서로 덮어써서 보상 메시지가 0.3초 만에 사라지는 경우 실측. 정보(진행)와 보상(획득)의 채널 분리 필요.
- **[Rules] 점수 반응이 시선 밖** — Severity: Low
  +10×콤보가 헤더 SCORE에만 적산 — 시선이 머무는 스포트라이트/카드 자리에서 점수 상승이 보이지 않는다 (보상 플로팅은 있으나 일반 매치 점수는 없음).
- **[Polish] 다중 폭탄 틱 소음** — Severity: Low
  폭탄 N개면 행동마다 tick이 N번 중첩 재생. 3개 이상이면 딸깍 벽이 된다.

### Confusion points
- 와일드 무장 후 **게이트 카드(열쇠/구역/종이)를 탭하면 거부**되는데, "와일드는 아무 카드나"라는 기대와 충돌 (규칙상 의도 — ADR-001 O-5 — 이나 첫 조우 시 토스트 원인 문구가 무장 상태를 언급하지 않음)
- 뒤집힌 카드(❔)가 free가 되기 전엔 탭해도 "위에 카드가 덮여 있어요"만 나옴 — 정보로서 정확하나 ❔의 정체를 설명할 기회를 놓침

### Moments of delight
- 콤보 5연쇄에서 **피치 계단 + 헤일로 + 셰이크 + 보상 2연타**(골드→와일드)가 겹치는 구간 — 이 게임의 최고 감각 순간 (레벨 3 실측)
- 게이트 해제 플래시: 구역이 열리는 순간 카드들이 일제히 반짝이며 커지는 연출 + sparkle 1회(중복 방지) — 절제가 좋다

- **Suggestions**: 획득 순간을 카니발급으로 (아래 개선안 1)

### 드로우 제한(↺) 레벨
- **Understood purpose?** Partially — 덱 숫자는 보이지만 "이 레벨은 드로우가 귀하다"는 선언이 플레이 화면엔 없음 (선택 화면 ↺ 아이콘뿐)
- **Suggestions**: 덱 ≤4 레벨은 덱 박스에 강조 테두리 + 시작 토스트 1회

## Quantitative Data
- **보정 주기**: pointerdown 즉시 상태 반영(<16ms) + 석션 300ms 트레일링 — 기준(100ms) 통과
- **연출 타이밍 실측(코드)**: 석션 300ms / 스쿼시 220ms / 헤일로 420ms / 셰이크 70~140ms / 언커버 팝 200ms / 게이트 플래시 460ms / 플로팅 900ms
- **오디오**: 어택 6ms, 마스터 게인 0.45, 콤보 계단 11단(C5 기준 펜타토닉)
- **레벨 3 실측**: 5연쇄 ~10초, 보상 2회, 골드 200→250, 와일드 ×1→×2, cgoal 보너스 +550

## Overall Assessment
- **Would play again?** Yes
- **Difficulty**: Just Right (곡선 14→44, 밴드 검증됨)
- **Pacing**: Good — 매치 리듬은 훌륭. 보상 순간의 낙차만 부족
- **총평**: **기본기(Response·ADSR·인과 연출)는 Swink 기준으로 상위권.** 이 게임의 필 문제는 "없다"가 아니라 **"정점이 평평하다"** — 가장 큰 순간(cgoal·보상·클리어)의 폴리시가 일상 매치와 같은 밀도라서, 폴리시 스펙트럼의 다이내믹 레인지가 좁다. 반대로 손실 순간(드로우·콤보 리셋)은 반응이 없어 리스크가 감각으로 전달되지 않는다.
