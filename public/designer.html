⚡ 자동 설계 (난이도 스케일 → 레벨)
스케일을 움직이면 아키타입 후보 8개를 생성·검증해 목표에 가장 가까운 레벨을 자동 선택합니다.
아직 실행 안 됨 — 슬라이더를 움직이거나 버튼을 누르세요.
🧪 대량 평가 (시뮬레이션 프레임워크)
현재 레벨을 대량 플레이하여 클리어율·예상 시행횟수·사용 아이템 수를 실측합니다.
📦 기존 레벨 편집
팩 레벨을 불러오면 보드·노브가 그대로 복원됩니다. 카드 클릭으로 심볼·잠금·폭탄·구역을 수정하고, 저장하면 원래 파일명(level-NNN.json)과 메타(스테이지·경제)를 유지한 채 갱신된 검증 지표로 내려받습니다.
▼ 아래 노브를 직접 조정하면 수동 모드로 전환됩니다 (팩 레벨에서 노브를 바꾸면 같은 시드로 보드가 재생성됩니다 — 카드 단위 수정은 보드 클릭).
A · 지각 (찾기 난이도)
서로 다른 심볼 종류. ↑ = 스캔 부담↑
r개 이상 공통 심볼이면 매칭 성공 (2~4개 매칭). r ≤ k 필요.
헷갈리는 심볼군을 함께 배치
B · 구조 (선택지·접근성)
패턴 예시는 패턴 갤러리 참고. 모든 패턴은 시드 기반 변형(봉우리 수·높이·구멍·진폭 등)이라 같은 패턴도 시드마다 다른 모양이 됩니다 — 🎲 시드를 바꿔보세요.
C · 자원 (여유)
D · 압박 (선택)
장애물 = 콤보 연속 ≥2 일 때만 제거 가능. 뒤집힌 카드 = 언커버 시 공개(봇 시뮬레이션엔 영향 없음 — 인간 지각 난이도).
F · 규칙 장치
🔑 자물쇠는 지정 열쇠 제거 후에만 선택 가능(해답 순서 기반 = 데드락 없음). 💣 폭탄은 표시된 수(手) 안에 제거 못하면 즉시 실패 — 카운터는 최단 제거거리+6. 🗺️ 구역은 왼쪽부터 순서대로 소진해야 다음 구역이 열림(경계 심볼 체인 자동 보장).
G · 콤보 보상 트랙
콤보가 값에 도달하면 아이템 지급(레벨당 1회) — 스타 카니발 연출로 터집니다. 낮은 콤보에 강한 아이템일수록 레벨이 쉬워지며, 난이도 점수(C자원)와 봇 시뮬에 자동 반영됩니다 (🌟와일드·🧲집게·🃏덱은 봇이 실제 사용, 🔍힌트·🪙골드는 인간 전용 → 정적 보정만).
E · 경제 (골드 보상 연동)
공식: 기본골드 = 15+3×레벨 · 점수환율 = 0.01×(1+난이도/40) · 패배 시 25% 위로보상.
→ 레벨·난이도가 오를수록 골드 획득이 점진 증가. 아이템 가격은 고정(🔍120·🧲350·🌟500) = 수입 성장이 곧 파워 진행.
디자이너 → 게임(game/play.html)으로 동일 레벨 스키마를 넘겨 즉시 플레이합니다. 보드의 카드를 클릭하면 직접 편집할 수 있습니다.
