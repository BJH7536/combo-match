스케일을 움직이면 아키타입 후보 8개를 생성·검증해 목표에 가장 가까운 레벨을 자동 선택합니다.
아직 실행 안 됨 — 슬라이더를 움직이거나 버튼을 누르세요.
🧪 대량 평가 (시뮬레이션 프레임워크)
현재 레벨을 대량 플레이하여 클리어율·예상 시행횟수·사용 아이템 수를 실측합니다.
▼ 아래 노브를 직접 조정하면 수동 모드로 전환됩니다 (자동 설계 결과에서 이어서 조정 가능).
A · 지각 (찾기 난이도)
서로 다른 심볼 종류. ↑ = 스캔 부담↑
r개 이상 공통 심볼이면 매칭 성공 (2~4개 매칭). r ≤ k 필요.
헷갈리는 심볼군을 함께 배치
B · 구조 (선택지·접근성)
C · 자원 (여유)
D · 압박 (선택)
장애물 = 콤보 연속 ≥2 일 때만 제거 가능. 뒤집힌 카드 = 언커버 시 공개(봇 시뮬레이션엔 영향 없음 — 인간 지각 난이도).
F · 규칙 장치
🔑 자물쇠는 지정 열쇠 제거 후에만 선택 가능(해답 순서 기반 = 데드락 없음). 💣 폭탄은 표시된 수(手) 안에 제거 못하면 즉시 실패 — 카운터는 최단 제거거리+6. 🗺️ 구역은 왼쪽부터 순서대로 소진해야 다음 구역이 열림(경계 심볼 체인 자동 보장).
E · 경제 (골드 보상 연동)
공식: 기본골드 = 15+3×레벨 · 점수환율 = 0.01×(1+난이도/40) · 패배 시 25% 위로보상.
→ 레벨·난이도가 오를수록 골드 획득이 점진 증가. 아이템 가격은 고정(🔍120·🧲350·🌟500) = 수입 성장이 곧 파워 진행.
